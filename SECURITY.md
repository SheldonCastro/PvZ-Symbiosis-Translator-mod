# Security Policy

Do not submit credentials, API keys, cookies, access tokens, private repository URLs, or unreviewed logs. Logs and diagnostics can contain local paths and machine-specific data; sanitize them before attaching.

For a security-sensitive report, use GitHub's private vulnerability reporting feature if it is enabled for the repository. No separate private contact address is currently published. If private reporting is unavailable, open a minimal issue that asks the maintainer to enable a private channel without including exploit details or secrets.

The project does not bundle the game, game binaries, generated IL2CPP assemblies, or MelonLoader. Reports about the base game or third-party loader should be directed to their respective maintainers.
