# Fonts

Each locale's `Fonts/manifest.json` defines ordered replacement and fallback fonts. The pt-BR source uses ContinuumBold as primary and Noto Sans as fallback. Translator Settings text deliberately uses the translator font policy; the Home launcher remains part of the game UI.

Font changes require runtime validation for accents, missing glyphs, layout, scene transitions, Settings reopen, and translation toggle. Keep the Noto OFL file with any redistribution.

ContinuumBold exists in private development material, but its presence does not prove redistribution rights. Exclude it from a public candidate unless the owner records a valid redistribution basis or replaces it with a cleared font.
