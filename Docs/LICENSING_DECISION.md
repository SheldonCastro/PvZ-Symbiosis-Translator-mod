# Licensing Decision

The project owner selected the standard MIT License on 2026-09-26. The original project source code and original project-owned material are licensed under the root `LICENSE`; that file contains the authoritative copyright notice.

The eventual source license cannot grant rights to:

- Plants vs. Zombies: Symbiosis or other game IP;
- game binaries, generated assemblies, or extracted assets;
- third-party fonts/artwork beyond their own licenses;
- localized derivative textures without a valid distribution basis.

This decision does not grant rights over third-party game content. ContinuumBold, uncleared UI artwork, the untranslated `Home.png` test, original game assets, and extracted material remain excluded from public promotion.
