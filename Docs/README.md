## Historical and internal reference

Files named `RECOVERY_*`, `AWAY_SESSION_REPORT`, `AUDIT_CURRENT`, `migration_review`, `TRANSLATION_REVIEW_NEEDED`, and milestone documents under `NativeUI` are dated development evidence. They are not current project authority and are excluded from public promotion. Contact sheets and native UI catalogs may contain game-derived visual/reference data and remain private.
