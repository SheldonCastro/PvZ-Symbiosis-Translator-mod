# Start a language pack

Copy this folder to a locale such as `es-ES`, then update its manifest and translate the values. Keep the original Chinese keys, placeholders, and ModStrings IDs unchanged.

See [Language packs](../../../Docs/LOCALIZATION.md) for the file formats and validation commands, and [Rich text](../../../Docs/RICH_TEXT_TRANSLATION.md) for formatting examples. Empty asset manifests are valid.
